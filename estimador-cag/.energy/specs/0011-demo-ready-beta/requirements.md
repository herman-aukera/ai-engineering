# Spec 0011 requirements: demo-ready beta

## Authority

The system shall preserve this chain: candidate -> deterministic hard gate -> independent semantic-judge panel -> jury result -> optional meta-judge -> deterministic action governor -> required human authorization -> bounded execution -> evidence -> reevaluation.

No proposal, judge, provider, tool, executor, vote, or meta-judge may authorize itself, override a hard failure, bypass required evidence, change server-owned privileges, or silently cause execution.

## Journey

The deterministic demo shall load a specification and policy, receive a typed provider-neutral coding proposal, repair one semantic defect, authorize a protected simulated action, record sanitized evidence, reevaluate, and expose repair, decision, evidence, and rollback records.

## Evidence boundary

CI remains keyless and network-free. Container configuration is not hostile-code isolation. HTML contract tests are not browser proof. OIDC configuration tests are not live SSO. Build assets are not deployment evidence.
