# EACHAT History Index

Git history is the authoritative archive for the earlier Energy-Aware Chat MVP, fixed benchmarks, evaluation endpoints and coursework-era product experiments.

Historical evaluator/proof documents remain useful as evidence, but they are not current production instructions. The current README and canonical architecture/security/operations/release documents define the product.

When the repository is split, keep only historical documents that explain important design decisions or reproduce still-relevant evaluation evidence; rely on Git for retired source code.
