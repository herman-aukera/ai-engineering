# EACODE History Index

Git history is the authoritative archive for EACODE SDD iterations, provider-routing experiments, Energy Core extraction research, sandbox adapters and production-hardening slices.

Historical specs/evidence that explain still-active security or architecture decisions may remain discoverable, but they are not current runtime/deployment instructions. Use the product README and canonical architecture/security/operations/release docs for present truth.

The archived `EACORE` branch remains research input; it is not a fourth canonical product and is not automatically the source of shared implementation.
