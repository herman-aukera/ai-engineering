# Estimator History Index

The repository evolved through many LIDR coursework sessions. Git history is the authoritative archive; historical source code should not be duplicated into archive directories.

Useful historical documentation remains indexed by `docs/HISTORICAL_SESSIONS.md` and the existing Session-specific evidence documents. These materials explain how retrieval, memory, streaming, RAG, agentic loops and LangGraph supervision evolved into the current estimator.

Historical documents are evidence/context, not current production instructions. Current runtime, CI, deployment and claim boundaries are defined by the top-level README and canonical architecture/security/operations/release documents.
