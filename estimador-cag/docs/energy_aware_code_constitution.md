# Energy Aware Code Constitution

status: active
scope: Energy Aware Code

## Core rule

Every candidate coding-agent step must lower verified constraint energy or be repaired, rejected, stopped, or escalated.

## Slice 1 boundary

This first slice builds the deterministic judge only.

It must not integrate provider calls, IDE adapters, terminal adapters, API endpoints, UI layers, or the bridge to Energy Aware Chat.

## Evidence rule

Model output and agent explanation are never sufficient proof. Proof comes from trusted evidence such as tests, lint, compile output, git diff, CI logs, or human approval records.
