# Energy Aware Chat demo evidence checklist

Use this checklist while recording or reviewing the final-project demo.

## Capture

- Current Git branch.
- Current commit SHA.
- Local validation result.
- CI result for the same commit.
- Streamlit screen showing the Energy Card.
- Accepted answer demo.
- One-pass repair demo.
- Project evidence demo.

## Boundary

Do not claim production readiness, deployment readiness, RAG grounding, or model quality improvement.
